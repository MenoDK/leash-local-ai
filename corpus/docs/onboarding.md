# Setting up a new laptop

## Accounts

Create the user account with a long passphrase and turn on disk encryption before anything else is installed. The
passphrase is never written on paper that stays with the laptop.

## Software

Install the standard set: a browser, an office suite, the password manager and the backup agent. Enrol the backup
agent last and run the first backup by hand to confirm that it reaches the file server.

## Handing it over

Show the new user where the guest wireless network and the printer are, and how to ask for a file to be restored.
Record the serial number in the inventory sheet.
