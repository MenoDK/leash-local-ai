# Software updates

## Patch window

Operating-system updates are installed on the first Tuesday of the month, after hours. Security fixes that are marked
critical are installed within two days, outside the window.

## Before updating

Confirm that last night's snapshot finished. Update the file server last, after the workstations, so that a bad update
is noticed on a machine that can be rebuilt quickly. Write the version before and after in the change log.

## If an update goes wrong

Boot the previous kernel from the boot menu, then roll back the package. If the machine does not boot at all, use the
recovery image described in the backups guide and restore last night's snapshot.
